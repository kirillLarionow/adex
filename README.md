# adex

Мини ad exchange на Go. Принимает аукционный запрос, фильтрует DSP-партнёров по условиям претаргетинга и параллельно отправляет им bid-запросы.

---

## Как запустить

Нужен Go 1.27+.

**1. Запустить мок DSP-серверы** (в отдельном терминале):

```bash
go run ./cmd/mockdsp
```

Поднимет три сервера: порты 9001, 9002, 9003. Сервер на 9003 отвечает с задержкой 500ms — для проверки таймаута.

**2. Запустить сам сервис** (в другом терминале):

```bash
go run ./cmd/adex
```

Сервис доступен на `http://localhost:8080`.

### Настройки

Все настройки задаются переменными окружения и необязательны:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ADDR` | `:8080` | Адрес HTTP-сервера |
| `PARTNERS_PATH` | `partners.json` | Путь к файлу партнёров |
| `AUCTION_TIMEOUT` | `200ms` | Время на весь аукцион |
| `DSP_TIMEOUT` | `3s` | Жёсткий таймаут одного запроса к DSP |
| `MAX_CONCURRENCY` | `50` | Максимум одновременных запросов к DSP |

Пример:

```bash
AUCTION_TIMEOUT=300ms MAX_CONCURRENCY=100 go run ./cmd/adex
```

При невалидном значении (не число, ноль или отрицательное) сервис не запускается и пишет, какая переменная неверна.

## API

### `POST /auction`

Принимает аукционный запрос, возвращает итог рассылки.

Ошибки:
- `405` — метод не POST
- `415` — `Content-Type` не `application/json` (вариант с `charset` принимается)
- `413` — тело запроса больше 1 МБ
- `400` — невалидный JSON, неизвестные поля, не заполнены `request_id` / `country`, неизвестный `device_type`, отрицательный `bid_floor`

### `GET /health`

Возвращает `200 OK`. Используется для проверки, что сервис жив.

## Пример curl-запроса

Запрос, на котором видна фильтрация:

```bash
curl -X POST http://localhost:8080/auction \
  -H "Content-Type: application/json" \
  -d '{
    "request_id": "req-1",
    "country": "RU",
    "device_type": "mobile",
    "bid_floor": 1.5,
    "categories": ["news", "sport"]
  }'
```

Пример ответа:

```json
{
  "request_id": "req-1",
  "matched_dsps": ["DSP Alpha", "DSP Beta"],
  "sent": 2,
  "succeeded": 1,
  "duration_ms": 201
}
```

Что произошло:
- DSP Gamma отфильтрована — категория `news` у неё заблокирована
- DSP Delta отфильтрована — `is_enabled: false`
- DSP Alpha прошла фильтрацию, но не ответила за 200ms (таймаут)
- DSP Beta прошла фильтрацию и ответила успешно

Логи сервиса покажут причину отклонения каждого партнёра.

## Где лежат партнёры и как добавить нового

Партнёры хранятся в файле `partners.json` в корне проекта (путь можно поменять через `PARTNERS_PATH`).

Чтобы добавить нового партнёра — добавить объект в массив:

```json
{
  "uuid": "unique-id",
  "name": "DSP New",
  "endpoint": "http://localhost:9004/bid",
  "is_enabled": true,
  "countries": ["RU", "US"],
  "device_types": ["mobile", "desktop"],
  "min_bid_floor": 1.0,
  "blocked_categories": ["adult"]
}
```

Правила фильтрации:
- `is_enabled: false` — партнёр полностью отключён
- `countries` — пустой массив означает «любая страна»
- `device_types` — пустой массив означает «любой девайс»
- `min_bid_floor` — партнёр не берёт запросы ниже этой ставки
- `blocked_categories` — если запрос содержит хоть одну из этих категорий — партнёр пропускается

Файл читается при старте, после изменения сервис нужно перезапустить.

## Тесты

```bash
go test ./... -race
```

Покрыто:
- **претаргетинг** — все правила фильтрации;
- **HTTP-хендлер** — метод, `Content-Type`, размер тела, невалидный JSON, неизвестные поля, валидация полей;
- **DSP-клиент** — успешный ответ, ответ не 200, отмена запроса по контексту;
- **сервис аукциона** — отправка только подходящим партнёрам, подсчёт успешных, таймаут медленного партнёра, ограничение конкурентности.

## Что бы я доделал при наличии времени

- **Горячая перезагрузка партнёров** — сейчас `partners.json` читается один раз при старте; хотелось бы reload по сигналу без перезапуска
- **Метрики** — количество аукционов, процент успешных отправок, latency по партнёрам (Prometheus)
- **Структурированные логи** — заменить `log.Printf` на `slog` с полями partner/request_id
- **Защита от проблемных DSP** — circuit breaker, чтобы временно не слать запросы партнёру, который постоянно падает или не отвечает
- **Остальные настройки в конфиг** — серверные таймауты, размеры пула соединений и лимит тела запроса пока заданы в коде
- **Docker** — `Dockerfile` и `docker-compose` для запуска сервиса вместе с моками одной командой
